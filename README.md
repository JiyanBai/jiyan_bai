# Jiyan Bai — academic website

A simple, responsive static website. `index.html` contains all CSS and JavaScript; the `assets` folder contains the headshot and CV.

## Publish with GitHub Pages

1. Download and extract the ZIP.
2. Upload **index.html** and the **assets** folder to the root of your GitHub repository `JiyanBai/jiyan_bai` (do not upload the ZIP itself).
3. Open repository **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
4. Visit https://jiyanbai.github.io/jiyan_bai/ after GitHub Pages publishes.

For a shorter URL, rename the repository `JiyanBai.github.io`, then use https://jiyanbai.github.io/.

## Editing

- Edit `index.html` in any text editor or GitHub's web editor.
- Replace `assets/profile.jpg` to update the headshot.
- Replace `assets/Jiyan_Bai_CV.pdf` to update the linked CV.
- The CV you supplied lists the Office of Mental Health position as **Aug. 2025–present**. If the appointment has concluded, update the date in both your CV and the site's Experience section.
- No external libraries, paid hosting, or build tools are needed.
