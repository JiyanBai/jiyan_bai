# Jiyan Bai — Academic Website

A responsive, static personal academic website built with HTML, CSS, and vanilla JavaScript. Inspired by the clean single-page structure of https://kbhasin.com/; all code and artwork are original.

## Preview
Open `index.html` in a web browser. For a local server: `python -m http.server 8000`, then visit http://localhost:8000.

## Publish with GitHub Pages
1. Create a public GitHub repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the root of the repository. Commit the changes.
3. Go to **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, **main**, **/(root)**, and **Save**.
4. Visit `https://YOUR-USERNAME.github.io/` when GitHub completes deployment.

If using a repository with a different name, its URL will generally be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Customize before publishing
- Replace the teaching placeholder with confirmed courses and roles.
- Add your preferred email address and professional profile links in the Contact section.
- Put your CV at `assets/Jiyan_Bai_CV.pdf` to make the CV link work.
- Optionally replace `.hero-art` in `index.html` with a headshot image.
- Edit papers and abstracts to match the public versions you wish to share.

No build process, npm packages, or backend is required. Google Fonts are used for type; system fallback fonts work if offline.
